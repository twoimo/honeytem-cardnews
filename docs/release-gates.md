# 운영 전환 게이트

이 문서는 구현 유무와 실제 운영 검증을 분리한다. 코드가 존재하거나 합성 테스트가 통과했다는 이유로 실제 상품·모델·Mac 성능을 통과 처리하지 않는다.

## 고정 범위

수정 대상은 `twoimo/honeytem-cardnews`만이다. 다른 봇 저장소의 롤백된 구현을 다시 적용하지 않는다. 기존 문서의 디자인·제휴·이미지 이용 조건을 유지한다. 새 기능은 선택 사항이며 기존 오프라인 실행은 네트워크를 사용하지 않는다.

## 승격 조건

1. 동일 입력의 기존 Python 기준선과 새 버전을 비교하여 카드 픽셀, 캡션, 원본 이미지, 링크, QA 의미가 유지되는지 확인한다. 코드 지문이 달라지므로 ZIP 전체 SHA의 동일성은 별도 항목이다.
2. 같은 머신·의존성·입력에서 반복 실행 시간과 메모리를 측정한다. 새 모델 실행·릴스 인코딩은 기존 카드 생성과 서로 다른 작업이므로 기존 기능의 속도 향상으로 섞지 않는다.
3. 실제 모델의 요청 ID/모델명/응답 사용량 등 제공되는 근거를 기록한다. 모의 HTTP 서버 테스트는 전송 계약 검증일 뿐 모델 품질 검증이 아니다.
4. 실상품 원문, 옵션, 가격, 배송 조건, 본인 발급 제휴 링크와 이미지 이용 권한을 운영자가 제공·검토한다. 모델은 권리나 소유를 승인할 수 없다.
5. 동일 입력으로 기존 승인 결과와 새 결과의 사실성·문체·미학을 비교한다. 승인된 기존 결과가 없으면 이 항목은 `미검증`이다.
6. 실제 대상 Mac에서 설치·실행·중단 복구·시간·최대 메모리를 측정한다. Linux 결과를 Mac 결과로 바꾸어 표현하지 않는다.
7. 필요한 검증이 완료된 뒤 검토 브랜치를 main에 반영한다. 검증되지 않은 부분이나 측정된 회귀가 있으면 보고하고 승격하지 않는다.

## 별도 권한이 필요한 운영 단계

외부 서비스 전송은 데이터·목적·대상과 비용 범위를 확인한 뒤 명시적으로 실행한다. 새로운 인증정보 발급이나 지속 접근 설정, 계정 권한 변경은 코드 작성 승인에 포함되지 않는다. 비밀값은 저장소·로그·결과물에 보관하지 않는다.

자동 게시, 예약 발행, 제휴 링크 발급, 약관 동의, 상시 서비스 설치는 이 구현의 자동 부수효과가 아니다. 출력의 `publish_ready=false`는 승인 파일이 있다고 해서 바뀌지 않는다. 검토 기록은 신원 인증이나 게시 권한을 대신하지 않는다.

## 증명 범위

계산 가능한 불변식(입력 보존, 프레임 수 합계, 파일 해시, 상태 전이)은 가정과 검증 방법을 문서화한다. AI 사실성·미학·모든 환경에서의 성능 무회귀는 수학적으로 증명했다고 주장하지 않는다. 관측된 샘플의 테스트 통과와 보편적 보장은 다르다.
