# 네 기능 구현 검증 기록 (2026-10-22 KST)

대상은 `honeytem-cardnews`의 상품 초안, 영속 작업 큐, 권리 기반 이미지 준비, 자막·제공된 오디오 합성 네 기능이다. 다른 저장소를 변경하지 않았다.

## 실행 결과

- 최종 전체 unittest: **234개 통과, 345.170초**, 건너뛴 테스트 없음. 병렬 검토 부하가 있는 테스트 전체 실행 시간이며 제품 처리 속도 측정값이 아니다.
- 독립 오류/공격 검증: **48개 통과**. 초안의 반올림 오류·권한 경계, 이미지 변환/원본 무결성, 큐의 영속 예산·중단·승인 복구·잠금 보존 등을 확인했다.
- 추가 독립 실미디어 검토: 29fps/25프레임의 모든 프레임 자막 영역·시각, 오디오 무결성, 6개 공격 사례 묶음과 5개 무결성 경계를 검증했다. 이는 위 234개 테스트에 더해지는 같은 종류의 실증이며 실제 모델 품질 증명이 아니다.
- 네 기능 통합 테스트: 합성 원본 이미지 준비 → 부분 상품 초안 → 명시적 TEST ONLY 검토·정식 manifest → 네트워크 없는 영속 카드/릴스 빌드 → 제공된 합성 음원 두 개와 한글 자막 합성 → 신뢰된 manifest 해시 재검증까지 통과했다. 실제 판매 권한이나 실상품 정보로 오인하면 안 된다.
- 모의 HTTP 서버를 통해 다상품 순차 처리, 연구 결과 검토 후 카피 반영, 429 예약, 실제 프로세스 종료 후 불명 요청 복구를 시험했다. 유료/실제 모델 API는 호출하지 않았다.

## 발견하여 수정한 문제

1. JSON 가격 소수가 binary float를 거쳐 다른 정수로 바뀌는 문제: float 가격 후보를 거부하고 정수·정확한 10진 문자열만 수용했다.
2. 승인 도중 종료하면 다음 manifest만 남아 후속 작업과 충돌하는 문제: 검토 영수증을 먼저 기록하고 동일 결정의 복구를 검증했다. 이미 묶인 결정과 다른 복구는 명시적으로 막는다.
3. 기존 build/reel lock 자동 삭제 위험: 활성·오래된 lock 모두 자동 제거하지 않고 운영자 확인을 요구한다.
4. SRT/번인 자막 사이의 ASS/backslash 해석 차이와 29fps 오디오 컨테이너 시간축 오차: 문자 경계 및 정확한 movie timescale을 적용하고 실제 결과를 디코딩했다.
5. 내부 해시만 다시 써서 자막 없는 영상을 끼워 넣는 경우: 자막 프레임·오디오로 MP4를 재생성하여 비교한다. 외부 신뢰 해시 없이는 전체 자료 교체의 작성자를 인증하지 못한다는 한계는 유지한다.
6. 매우 긴 JSON 정수의 원문 ValueError: Python 자릿수 제한은 유지하고 공통 입력 경계에서 안전한 ValidationError로 변환했다.

## 기존 카드 경로의 전후 비교

기준선은 main 반영 시점 `04a84c9`의 실행 코드이며, 동일 원본 합성 fixture, 동일 의존성/환경, 변경하지 않은 비교 도구로 cold/resume **15쌍**을 실행했다. 소스 해시는 측정 전후 같았다.

| Resume 실행 | 0.133304초 | 0.132098초 | 미결론 |

7개 이미지에서 변경 픽셀 0, 카드 PNG·캡션·원본 링크·QA·원본 이미지 바이트가 동일했다. 추가 코드 신원 기록으로 ZIP이 326바이트 늘었으며 이미지 크기는 증가하지 않았다. ZIP 전체 SHA 동일성을 주장하지 않는다.

허용치 0%를 변경하지 않았다. 일부 비교 구간이 1을 걸치므로 전체 정량 비회귀는 **미결론**, 실제 모델/상품/Mac까지 포함한 전체 무회귀는 **미검증**이다. 이 실험에서 회귀로 분류된 지표는 없지만, 그것이 모든 환경의 무회귀 증명은 아니다.

## 산출물과 범위

실제 H.264/AAC 검증 클립은 합성 도형과 공개 수학적 신호 두 트랙이다. 사람 목소리나 TTS, 실제 상품 추천 콘텐츠가 아니다. 원래 무음 영상/manifest도 보존했다.

구현된 네 기능의 명령·입출력·불변식은 [통합 안내](four-feature-workflow.md)를 따른다. 실제 웹 수집, 새 모델 설치·계정·인증정보 설정, TTS 서비스 호출, 외부 게시·예약 발행·상시 운영은 이 네 기능의 자동 부수효과가 아니다. `publish_ready=false`를 유지한다.
