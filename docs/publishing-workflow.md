# 인스타그램 발행 워크플로

확인일: 2026-10-21. 이 문서는 수동 운영 절차이며 자동 발행 기능이 아닙니다.

## 1. 상품 번호를 먼저 고정
한 게시물의 추천 상품을 01, 02, 03처럼 번호로 묶습니다. 카드 → 캡션 → 프로필 링크 제목의 번호·상품명을 일치시킵니다. 링크를 나중에 다른 상품으로 바꾸어 과거 게시물이 엉뚱한 상품으로 연결되지 않게 합니다.

## 2. 링크 위치 선택
- **프로필**: 앱의 프로필 편집 → 링크에 전용 URL을 넣고 `01 머그 · 프로그램명`처럼 이름을 붙입니다. Meta는 프로필에 최대 5개 외부 링크를 지원한다고 안내합니다. [Meta 공식 안내](https://about.fb.com/ko/news/2023/04/instagram%EC%9D%B4-%EC%9E%90%EC%9C%A0%EB%A1%9C%EC%9A%B4-%EC%9E%90%EA%B8%B0%ED%91%9C%ED%98%84%EC%9D%84-%EB%8F%95%EB%8A%94-%EC%83%88%EB%A1%9C%EC%9A%B4-%EA%B8%B0%EB%8A%A5%EC%9D%84-%EC%84%A0%EB%B3%B4/) / [메뉴 경로 안내](https://linktr.ee/help/en/articles/5434089-add-linktree-url-instagram-bio)
- **스토리**: 상품별 카드 → 스티커 → 링크 → 원본 제휴 URL. 링크 버튼을 광고 표시·본문과 겹치지 않게 놓습니다. 새 계정 등에서는 기능이 제한될 수 있습니다. [Meta 공식 안내](https://about.fb.com/ja/news/2021/10/linkaccessstickers/)
- **피드 캡션**: URL만 적고 끝내기보다 `프로필 링크에서 01·02·03번 확인`처럼 행동 경로를 명확히 합니다. 캡션 링크 기능은 계정·시점별 차이를 실제 앱에서 확인하고 보편 제공된다고 가정하지 않습니다.
- **링크 모음 페이지**: 필요할 때만 사용합니다. 해당 프로그램의 채널 등록·리디렉션 허용 여부를 확인하고, 페이지에도 수수료 관계와 상품 번호를 표시합니다. 이번처럼 상품 3개라면 프로필의 직접 링크부터 검토합니다.

## 3. 작성 순서
1. 프로그램·발급 주체·공유 채널을 확인합니다.
2. 원본 상품과 옵션·가격·이미지 사용 권리를 확인합니다.
3. [공통 규칙](../rules/affiliate-common.md)과 해당 프로그램 문서를 적용합니다.
4. [캡션 템플릿](../templates/caption-ko.md)의 대괄호를 실제 확인값으로 바꿉니다.
5. 카드의 디자인을 검수한 뒤 링크가 의도한 상품으로 열리는지 확인합니다. 직접 구매나 반복 클릭으로 수익을 시험하지 않습니다.
6. 운영자 검토 후 게시합니다. 게시 요청이 없으면 초안 상태로 반환합니다.

## 4. 발행 체크리스트
- [ ] 실제 상품과 생성 콘셉트가 구분되어 있다.
- [ ] 상품명·옵션·가격 조건·확인 시각이 일치한다.
- [ ] 사진 사용권과 편집 허용 범위를 확인했다.
- [ ] 원본 추적 URL을 보존했다.
- [ ] 활동 채널 등록·승인과 최신 정책을 확인했다.
- [ ] 캡션 첫 줄·첫 카드·스토리의 광고 안내가 식별된다.
- [ ] 이미지/카드/링크 목록의 번호가 같다.
- [ ] 템플릿의 미확인 값·자리표시자·테스트 주소가 남지 않았다.
- [ ] 운영자가 게시를 승인했다.

## 5. 발행 후 점검
이 저장소의 운영 제안입니다. 게시 직후 링크와 표기를 확인하고, 상품 품절·참여 종료·가격/프로모션 변경을 알게 되면 문구와 연결을 수정하거나 게시를 중단합니다. 수익 성과는 승인된 채널에서 확인된 대시보드 수치로만 기록하며, 정산되지 않은 금액을 매출 성과로 확정하지 않습니다.

## 반환 형식
- 카드뉴스 초안
- 캡션
- 상품 번호별 원본 링크 목록
- 확인 시각과 출처
- 미확인 항목/발행 보류 이유

외부 계정 생성, 정산 서류 제출, 실제 링크 발급, 외부 게시 권한은 별도입니다. 비밀번호·주민등록번호·계좌 정보는 문서나 캡션에 넣지 않습니다.
