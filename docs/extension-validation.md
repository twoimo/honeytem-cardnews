# 2차 구현 검증 기록 (2026-10-21)

## 실제 실행한 범위

- 저장소 전체 unittest: 122개 통과 (최종 실행 56.157초). 이 시간은 테스트 묶음 소요 시간이며 운영 성능 비교가 아니다.
- 별도 검토의 공격/오류 입력 검증: 네트워크 경계, 응답 변형을 통한 인증정보 반사, 느린 헤더, 불확실 요청 재시도, 영상 실패와 변조 등을 검토했다. 실제 계정 인증정보나 유료 API는 사용하지 않았다.
- 기준선 a85780b의 렌더러와 변경 렌더러를 동일 입력으로 직접 비교하여 10개 모든 변형의 PNG 바이트와 QA 전체가 정확히 동일함을 확인했다.
- 실제 FFmpeg/FFprobe로 1080×1920, 30fps, 360프레임, 12초의 무음 합성 샘플을 생성·검증했다. 영상은 손실 압축이므로 원본 PNG와 MP4 픽셀의 동일성을 주장하지 않는다.
- 공급자 클라이언트는 루프백 HTTP 서버를 통한 전송 계약을 검증했다. 실제 모델 호출 성공이나 모델 품질 평가가 아니다.

## 발견 후 수정한 결함

- 1프레임 장면의 concat 시간축에서 일부 프레임이 빠지는 문제: 전역 프레임 시각에 맞춰 interleave하고 실제 저/고 FPS 인코딩으로 재검증.
- Unicode 이스케이프/이미지 metadata를 이용한 런타임 비밀값 반사: 최종 해석 결과와 이미지 데이터를 추가 검사. 원문 오류 응답을 로그로 남기지 않음.
- 천천히 도착하는 응답 헤더가 단순 socket timeout을 우회하는 문제: 연결 시도 단위 watchdog 적용. OS DNS 시간은 별도 제한임을 공개.
- 공개 IP 판정만으로 multicast를 허용하는 문제: literal/DNS 결과에서 multicast·reserved·unspecified·site-local 및 mapped 형태 차단.
- 직전 페이지를 보유한 상태에서 다음 canvas를 할당하는 문제: PNG와 QA 저장 후 이미지 close/del. 10개 변형의 출력 바이트를 재대조.

## 성능: 통과와 미확인을 분리

[15쌍 전후 비교 방법과 전체 수치](regression-method.md)를 참조한다. 기준선과 입력, 비교 절차 및 0% 허용 기준은 유지했다. 구현 변경 이전 측정도 삭제하지 않고 서로 다른 소스의 기록으로 구분했다.

최종 측정에서 기존 카드 출력은 동일하고 cold 최대 RSS는 약 2.57MB 감소했다. 하지만 cold 실행 시간 중앙값은 약 4.98% 높게 관측되었으며 비교 구간은 증가/감소 양쪽에 걸쳐 있어 미결론이다. resume RSS 역시 미결론이다. 따라서 전체 정량 비회귀를 통과 처리하지 않고 main 운영 전환을 보류한다. 평균/중앙값 하나만 선택해 성능 향상이라 주장하지 않는다.

## 아직 실행하지 않은 것

실제 상품·소유 제휴 링크·이미지 이용 조건의 검증, 실제 모델의 사실성/미학/비용 비교, 대상 Mac 실측은 입력과 접근/실행 권한이 필요하다. 처음 상품을 찾는 웹 조사, TTS·음악, 외부 게시·예약 발행, 제휴 링크 발급, 상시 운영 설치를 완료했다고 주장하지 않는다. AI 연결은 명시적 호출 클라이언트이며 독립적으로 계속 돌아가는 서비스가 아니다.

이 기록은 검토 브랜치의 코드 검증 근거이다. 실제 판매 승인, 보안 인증, 모든 입력/환경의 무결함 또는 성능 무회귀 증명이 아니다.
