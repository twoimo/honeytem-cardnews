# Main 반영 상태 (2026-10-21)

사용자는 미완료 검증 범위를 안내받은 뒤 사용량 설정이나 Mac 재실행 없이 현재 구현을 main에 반영하도록 명시적으로 요청했다. 이 반영은 코드의 기본 브랜치 편입이며, 모든 운영 검증의 통과 선언이 아니다.

반영 코드: a038d2312898d2e8b5f03147eb2e30e45a68aa90. 이 기록을 추가하면서 실행 코드는 변경하지 않는다. 기존 문서의 main 보류 설명은 그 작성 당시의 상태이며, 이번 명시적 요청으로 브랜치 편입에 한해서 대체한다. 테스트나 성능 판정은 변경하지 않는다.

- 전체 테스트 122개 및 별도 공격/오류 검증 16개 통과 기록은 유지한다.
- 10개 레이아웃의 기존/변경 PNG 바이트와 QA 동일성 확인은 유지한다.
- 전체 정량 성능 비회귀는 미확인이다. 실제 모델 품질·비용, 실상품 정보·제휴 링크 소유·이미지 권한, Mac 실측도 완료되지 않았다.
- 기본 빌드는 오프라인이다. 모델 호출은 명시적 선택 사항이며, 자동 게시·예약 발행·상시 서비스·신규 인증정보 설정을 활성화하지 않는다.
- main 반영 자체는 실제 상품 게시 승인, 새 데이터 전송 권한, 모델 비용 승인 또는 사용량 제한 우회를 뜻하지 않는다.
