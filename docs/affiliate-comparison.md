# 세 제휴 프로그램의 선택 기준

확인일: **2026-10-21**. 이 문서는 추천 수익률 순위가 아니라 **카드뉴스 운영 적합성 비교**입니다. 실제 상품·채널·권리·조건이 확인된 프로그램만 선택합니다.

| 항목 | 토스 쉐어링크 | 쿠팡 파트너스 | 선물하기 큐레이터 |
| --- | --- | --- | --- |
| 링크 입력 | 본인 쉐어링크 | 본인 파트너스 링크 | 본인 큐레이터 전용 링크 |
| 주의할 혼동 | 일반 상품 공유·초대 이벤트 | 일반 쿠팡 URL·앱 공유 | 일반 선물하기 공유 |

| 자동화 판단 | 신규 Open API 신청 중단 확인 | API 권한·정책 별도 확인 | 공개 자동 발급 지원 미확인 |

표의 구체 근거와 한계는 [토스](../rules/toss-sharelink.md), [쿠팡](../rules/coupang-partners.md), [카카오](../rules/kakao-gift-curator.md)에 있습니다. **프로그램 간 수익률·귀속·환불 규칙을 공유 상수로 만들지 않습니다.**

## 운영 제안
다음은 공식 플랫폼 추천이 아니라 이 저장소를 위한 설계 판단입니다.

1. **처음에는 한 게시물에 한 프로그램**을 권합니다. 가격·이미지 권리·수수료 고지·실적 확인을 단순하게 유지할 수 있습니다.
2. 선물 전용 구성은 카카오, 폭넓은 생활용품 비교는 쿠팡, 토스쇼핑 대상 상품은 토스 등으로 탐색할 수 있지만, **상품이 실제 대상인지 확인한 뒤** 결정합니다. 높은 표시 수익률만으로 추천 순서를 정하지 않습니다.
3. 기존 흰 배경·매거진 톤은 유지하되, 토스처럼 제공 사진을 가공할 수 없는 경우는 원본 보존형을 검토합니다. 모든 프로그램에 누끼를 일괄 적용하지 않습니다.
4. 상품·권리 증거가 없으면 콘셉트 모드로 반환합니다. 제휴 CTA와 임의 가격을 넣어 ‘완성’시키지 않습니다.
5. 링크 허브나 자동화는 첫 단계 필수가 아닙니다. 실제 운영 채널과 상품 몇 개로 시작하고, 권한·지원 범위가 확인된 기능만 추가합니다.

## 수익 비교 시 남길 것
수익률 하나 대신 아래를 함께 비교합니다.
- 상품·기간·적용 시점별 요율
- 직접/간접 구매와 마지막 클릭 등 귀속 조건
- 취소·반품·구매확정 시점
- 채널 등록·최종승인·지급 최소액·증빙
- 고객에게 보이는 가격·배송·반품 조건
- 사진 사용·편집 가능 범위와 수작업 비용

‘조회수 × 수수료율’로 수익을 추정하지 않습니다. 노출 → 유효 클릭 → 인정 주문 → 확정 → 지급의 단계별 데이터가 있어야 비교 가능합니다.

## 이번 조사에서 남긴 한계
- 토스: 비율 유지 리사이즈나 외부 AI 전달 등 세부 사용 방식까지 포괄 허가로 보지 않았습니다. 최신 공지로 변경되는 조건은 발행 직전 확인합니다.
- 쿠팡: 2026-09-07 약관은 확인했지만 최신 운영정책·일부 공지 원문은 공개 조회 차단으로 미확인입니다. 가이드 기반 숫자는 현재 계정에서 재검증합니다.
- 카카오: 공개 공식 발표 이상의 세부 귀속·정산·채널 조건은 미확인입니다. 기존 문구도 링크 발급 화면과 최종 대조합니다.
- 세 프로그램 모두 사용자의 가입·승인·링크 소유권·수익 발생 여부는 조사하지 않았습니다.

## 우선순위
법령·프로그램의 적용 약관/최신 공지 → 상품별 사용 권리 → 공통 제작 규칙 → 시각 스타일 순으로 검토합니다. 출처가 충돌하면 적용 대상과 시행일을 기록하고, 해결 전 해당 내용을 확정 게시하지 않습니다.
