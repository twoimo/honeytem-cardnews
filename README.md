# 🍯 꿀템 카드뉴스

**제휴 링크 하나로, 인스타그램 꿀템 카드뉴스 초안을 한 번에.**

토스 쉐어링크 · 쿠팡 파트너스 · 카카오톡 선물하기 큐레이터 링크를 받아<br/>
카드뉴스 이미지, 캡션, 링크 목록을 만드는 Grok Bot 설정과 운영 규칙입니다.

## ✨ 무엇을 하나요

| 입력 | 출력 |
| --- | --- |
| 본인 계정에서 발급한 제휴 링크 + 프로그램명 | 🖼️ 카드뉴스 초안 |
| 상품명·옵션·가격·사용 가능한 원본 이미지 | ✍️ 대가성 문구를 포함한 캡션 |
| 선택: 주제·대상·채널 | 🔗 상품 번호와 연결된 링크 목록·검수표 |

> 일반 상품 공유 링크와 수익 추적용 제휴 링크는 다릅니다. URL 모양만 보고 본인 실적이나 수익을 보장하지 않습니다.

이 저장소는 **봇 설정과 문서**입니다. API 연동, 링크 자동 발급, 이미지 렌더러, 예약 발행 기능을 구현한 앱은 아닙니다.

## 🚀 빠른 시작

1. 프로그램명과 **이미 발급된 본인 제휴 링크**를 붙여 넣습니다.
2. 상품·옵션·가격·사진 사용 범위를 확인합니다. 조회가 막히면 확인 가능한 자료를 받아 작업합니다.
3. [플랫폼별 비교](docs/affiliate-comparison.md)와 해당 규칙을 적용해 이미지·캡션·링크 목록을 만듭니다.
4. [발행 체크리스트](docs/publishing-workflow.md)를 통과한 뒤 운영자가 게시합니다.

상품 정보가 없으면 **AI 콘셉트 샘플**만 만듭니다. 가짜 가격, 임의의 추천인 코드, 실제 상품인 척하는 이미지로 채우지 않습니다. 가입·약관 동의·정산 정보 등록·외부 게시를 링크 제공만으로 자동 진행하지 않습니다.

## 🎨 디자인 원칙

- **흰 배경 매거진형**: 작은 마스트헤드 + 페이지 번호, 제품 중심 이미지, 굵은 한 줄 제목과 확인된 가격, 1~2줄 코멘트
- **10가지 변형**을 게시물마다 돌려 쓰기
- **미니멀 + 힙함**: 개성 있는 선, 독특한 타이포, 스티커·태그
- 배경은 흰색 · 오프화이트 · 연회색 · 검정만
- 🚫 형광펜 하이라이트, 원색 배경 금지

누끼는 이미지 이용 조건이 허용할 때만 적용합니다. **프로그램별 이미지 권리 규칙이 공통 디자인보다 우선**합니다. 자세한 내용은 [디자인 규칙](rules/design.md)을 보세요.
