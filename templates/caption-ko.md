# 한국어 캡션 템플릿

대괄호는 작성용 자리표시자이며 실제 게시 전 확인한 값으로 교체합니다. 아래 템플릿은 구매 유도용 계정 가입이나 외부 게시를 실행하지 않습니다.

## 1. 대가성 첫 문단: 사용하는 프로그램만 선택

### 토스 쉐어링크
[광고] 토스쇼핑 쉐어링크 활동으로, 링크 구매 시 수수료를 지급받습니다.

출처: [토스 공식 짧은 문구](https://sharelink-docs.toss.im/disclosure).

### 쿠팡 파트너스
[광고] 이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.

출처: [쿠팡 공식 가이드 p63](https://partners.coupangcdn.com/partners-guide/partners-guide-20251028182159.pdf). 발행 시 현재 안내와 대조합니다.

### 카카오톡 선물하기 큐레이터
[광고] 이 포스팅은 선물하기 큐레이터 활동의 일환으로, 주문 발생 시 일정액의 수수료를 제공 받습니다.

기존 저장소 채택 문구입니다. 링크 생성 화면의 최신 안내와 대조합니다. [확인 범위](../rules/kakao-gift-curator.md)

둘 이상을 혼합하면 실제 사용하는 프로그램별 문구를 누락하지 않습니다. 상품 협찬·별도 광고비 등 추가 관계가 있으면 별도 명시합니다.

## 4. 링크 목록과 스토리
링크 목록은 `01 | 상품명·옵션 | 프로그램명 | 발급 원본 URL | 확인 시각` 형태로 관리합니다. 실제 URL 대신 추정 주소를 만들지 않습니다.

스토리는 해당 프로그램의 수수료 문구 + 상품명/번호 + 실제 링크 스티커로 구성합니다. 첫 화면에서 안내가 읽히도록 하고, 생성 이미지를 쓰면 AI 표시도 함께 검수합니다.
