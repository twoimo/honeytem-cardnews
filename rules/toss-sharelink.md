# 토스쇼핑 쉐어링크

확인일: **2026-10-21**. 공식 가이드와 날짜가 있는 최신 공지를 함께 확인합니다. 아래 수치는 확인 시점 스냅샷이며 상시 보장이 아닙니다.

## 링크·참여
일반 토스쇼핑 공유나 친구 초대가 아닌 구매 성과형 제휴 프로그램입니다. 앱에서는 ‘팔릴 때마다 돈 버는 링크 공유하기’, PC에서는 링크 발급으로 만든 본인 URL을 사용합니다. 일반 상품 URL과 API의 `productUrl`을 제휴 링크로 쓰지 않습니다. [링크 생성](https://sharelink-docs.toss.im/create-sharelink.md), [링크 API](https://sharelink-docs.toss.im/developers/open-api/api/link)

만 19세 이상 내국인, 비사업자도 참여할 수 있습니다. 웹의 토스 비즈니스 가입과 쉐어링크 가입은 별도이며 실제 활동 채널을 등록해야 합니다. 본인 가입·승인 여부는 별도 확인합니다. 신원·정산 정보는 공식 화면에서 직접 처리하고 저장소에 넣지 않습니다. [가입](https://sharelink-docs.toss.im/start.md), [개인](https://sharelink-docs.toss.im/start/individual.md), [채널](https://sharelink-docs.toss.im/start/channels.md)

## 구매 인정·정산
- 클릭 후 24시간 안의 결제와 마지막 클릭 기준을 적용합니다. 조건에 맞으면 다른 상품의 간접기여도 인정되지만 예외가 있습니다.
- 본인 구매, 가족·지인 동원 교차결제, 본인 운영 상점 거래는 제외됩니다.
- 구매확정 전 취소·환불은 예상 수익에 영향을 줍니다. 가이드는 **구매확정 후 환불은 확정 수익금을 줄이지 않는다**고 구분합니다.
- 단순 클릭은 수익이 아닙니다. [수익 인정 기준](https://sharelink-docs.toss.im/income/earnings/earnings-rules)
- 구매확정월 다음 달 25일 지급 안내이며 휴일은 다음 영업일로 조정됩니다. 최소 잔액 10원 및 사업자별 증빙·승인 조건을 확인합니다. [지급](https://sharelink-docs.toss.im/income/settlement-guide/payment.md)

## 날짜가 중요한 공지
[공식 공지](https://sharelink-docs.toss.im/notice) 확인 결과:
- 2026-10-01 이후 **구매확정분**은 8% 프로모션(기본 5%+한시 3%). 과거 10%를 상수로 쓰지 않습니다.
- 오아시스: 간접기여 인정은 2026-10-12부터, 5% 요율은 2026-10-26 00:00 KST부터입니다. 수익 기준 본문의 간접기여 제외 문구와 충돌하므로 날짜가 있는 변경 공지와 계정 안내를 재확인합니다.
- 앱인토스 미니앱 경유 주문은 2026-11-03 00:00 KST 이후 구매확정분부터 정산 제외. 앱 밖 공유에는 같은 종료 조건을 적용하지 않습니다.
- 첫 구매 3,000원 쿠폰 이벤트는 종료 표시입니다.

## 사진 사용: 공통 누끼 규칙의 예외
공식 운영정책은 쉐어링크 상품 소개 목적의 썸네일·상세 이미지 사용을 허용하고 썸네일 사용을 권장하지만, **원본의 크롭·합성·편집·번역을 금지**합니다. 이미지 사용 금지 표시 상품은 썸네일까지 제외하며 셀러 삭제 요청에 대응해야 합니다. 타인의 후기·방송·게시물은 이 허용 범위가 아닙니다. 사칭, 자동실행·무효 클릭, 광고금지 커뮤니티, 무동의 광고 메시지도 금지합니다. [공식 운영정책](https://sharelink-docs.toss.im/help/operations/policy.md)

**저장소 적용안**: 원본 사진 자체를 변형하는 배경 제거·오브젝트 재생성은 하지 않습니다. 허용 범위를 확인한 원본 이미지 영역과 그 바깥의 마스트헤드·제목·설명 영역을 분리하는 안을 검토합니다. 이는 토스가 개별 레이아웃을 승인했다는 뜻이 아닙니다. 비율 유지 리사이즈·문구 오버레이까지 허용된다고 추정하지 않으며, 불명확하면 원본 사용 방식 확인 또는 자체 촬영 등 별도 권리가 확보된 소재로 전환합니다.

첫 화면에서 수수료 관계를 읽을 수 있게 하고 프로필에만 표시하지 않습니다. AI 이미지는 AI임을 별도 표시합니다. 공식 짧은 문구는 [캡션 템플릿](../templates/caption-ko.md)에 수록했습니다. [공식 표시 가이드](https://sharelink-docs.toss.im/disclosure)

## 자동화·URL 변경
- 확인일 현재 **Open API 신규 신청·반려 후 재신청은 중단**이며 기존 승인자는 이용 지속 가능합니다. SNS·블로그 자동화와 가격 DB를 이용한 커머스·비교 사이트는 같은 허용 범위가 아닙니다. [Open API 안내](https://sharelink-docs.toss.im/developers/open-api.md), [연동 시작하기](https://sharelink-docs.toss.im/developers/open-api/auth)
- 기본 경로는 운영자가 발급한 URL과 확인한 상품 정보의 수동 입력입니다. 수집·캐싱·외부 AI API로의 상품 데이터 전송 권한을 API 접근만으로 추정하지 않습니다. [FAQ의 Open API 사용 범위](https://sharelink-docs.toss.im/help/troubleshooting.md#open-api)
- API의 `shortUrl`/`originUrl`은 반환값 그대로 씁니다. 공식 예외인 `originUrl`의 `partner_ref_id`만 문서에 따라 검토하며 기존 `k`/`referrer`는 보존합니다. `shortUrl`에 임의 파라미터를 추가하지 않습니다. [링크 API](https://sharelink-docs.toss.im/developers/open-api/api/link)
- 신규 키 발급·실제 API 호출은 본 문서 추가 작업에 포함되지 않습니다.
