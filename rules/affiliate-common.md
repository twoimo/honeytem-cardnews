# 제휴 콘텐츠 공통 규칙

확인일: 2026-10-21. 플랫폼의 최신 약관·공지와 상품별 권리 조건이 우선합니다. 아래의 추가 검수 절차는 이 저장소가 채택한 보수적 운영 기준입니다.

## 1. 링크와 상품 증거
- `program`은 `toss_sharelink`, `coupang_partners`, `kakao_gift_curator` 중에서 확인합니다. 일반 공유·초대 이벤트·제휴 링크를 혼동하지 않습니다.
- 운영자가 본인 계정에서 발급한 원본 URL을 받습니다. 도메인이 맞아도 소유자·계정 상태·실적 인정까지 입증된 것은 아닙니다.
- 링크를 임의로 재조립하거나 추적 파라미터를 삭제·추가하지 않습니다. 단축·리디렉션·UTM은 각 프로그램이 허용하는 방식을 확인한 경우에만 씁니다.
- 상품명, 판매자, 옵션, 수량, 가격 기준, 배송비, 쿠폰·회원 조건, 확인 시각을 기록합니다. 옵션이 다른 상품의 최저가나 리뷰를 가져오지 않습니다.
- 조회 실패는 ‘품절’이나 ‘접근 불가 상품’의 증거가 아닙니다. 확인 가능한 상품 화면이나 공식 자료를 요청하고 가격·혜택 판단을 보류합니다.
- 추적 링크는 게시에 필요할 때만 사용합니다. 회원번호·계좌·세금 서류·인증정보를 이 공개 저장소에 저장하지 않습니다.

## 2. 광고 표시
판매가 발생한 뒤 받는 수수료도 경제적 이해관계 공개 대상입니다. 불확정적인 문장으로 광고 관계를 흐리지 않습니다. [공정위 2024 개정 안내](https://eiec.kdi.re.kr/policy/materialView.do?num=259681)

이 저장소의 기본 배치:
- 캡션 첫 줄에 `광고`와 해당 프로그램의 수수료 문구를 둡니다.
- 첫 카드와 링크가 있는 스토리에도 알아보기 쉬운 광고 표시를 둡니다.
- 프로필·댓글·해시태그 더미에만 적거나 ‘더보기’ 뒤에만 숨기지 않습니다.
- 혼합 프로그램 게시물은 사용한 프로그램을 모두 명시하고, 상품별 링크 목록에 프로그램을 표시합니다.
- 상품 무상 제공, 별도 광고비 등 추가 관계가 있다면 수수료 문구만으로 끝내지 않습니다.
- 플랫폼의 제휴/유료 파트너십 표시 기능이 해당되는 경우 그 요구도 별도 확인합니다. 캡션 문구와 플랫폼 도구를 서로 대체한다고 가정하지 않습니다.

## 3. 상품 사진과 AI
- 공식 제공·직접 촬영·명시적으로 허용된 사진만 허용 범위 안에서 사용합니다. ‘웹에 공개됨’은 사용·수정 허가가 아닙니다.
- **실제 판매 모드**: 상품 형상·색·로고·구성품을 보존하고, AI가 만든 유사 제품을 진품 사진처럼 쓰지 않습니다. 사용하지 않은 상품을 ‘직접 써봄’, ‘내돈내산’으로 표현하지 않습니다.
- **콘셉트 모드**: 모든 이미지에 `콘셉트 샘플 · AI 이미지`를 표시합니다. 실제 상품과 대응되지 않으면 판매용 링크·가짜 가격을 붙이지 않습니다.
- AI 안내가 허위 제품 묘사나 이미지 권리 위반을 허용해 주지는 않습니다.
- AI 가상인물이 추천하는 광고에는 가상인물임을 명확히 표시해야 합니다(2026-06-01 시행). 제품만 생성한 이미지와 가상 추천인 규정을 혼동하지 않되, 본 저장소는 생성 이미지 자체도 투명하게 표시합니다. [공정위 안내](https://www.korea.kr/news/policyNewsView.do?newsId=148968915)

## 4. 수익·조건 표현
- 클릭수, 주문액, 예상 수익, 확정 수익, 입금액을 구분합니다. 클릭만으로 보상이 생긴다고 쓰지 않습니다.
- 수익률과 할인율은 다릅니다. 제휴 수수료를 구매자 할인으로 바꾸어 설명하지 않습니다.
- 인정 기간·직접/간접 구매·마지막 클릭·취소/환불·세금·최소 지급액은 **프로그램별**로 확인합니다.
- 확인되지 않은 ‘무조건 지급’, ‘최저가’, ‘평생 유효’, ‘추가 비용 없음’, ‘누구나 승인’을 쓰지 않습니다.
- 공지 간 충돌은 시행일과 적용 대상(주문일/구매확정일/채널)을 대조하고, 해결 전 해당 숫자·주장을 게시하지 않습니다.

## 5. 공개 전 최소 레코드

```yaml
program: 확인 필요
issued_url: 운영자가 발급한 원본 링크
product_name: 확인 필요
seller_and_option: 확인 필요
price_and_conditions: 확인 필요
checked_at: YYYY-MM-DDTHH:mm:ss+09:00
image_source_and_license: 확인 필요
allowed_image_edits: 확인 필요
disclosure_text: 해당 프로그램에서 확인한 문구
channel_status: 등록/승인/확인 필요
mode: concept 또는 affiliate
publish_ready: false
```

`publish_ready`는 작업용 검수 상태일 뿐 플랫폼 승인·정산 보증이 아닙니다. 정보가 채워지지 않으면 초안으로 유지합니다.
